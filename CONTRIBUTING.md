# Contributing

⚠️ **A pull request opened here cannot be merged** — not as a matter of policy, but
mechanically: this repository is a mirror, regenerated by an allowlist export from a
private source repository, and the next export would overwrite it. Please do not read an
unmerged PR as an ignored one.

## The path that does work

1. **Open an Issue** — for bugs, questions, and anything you would like discussed. Issues
   are read, and they are the intended contact channel.
2. **A patch is welcome inside that Issue** — a diff, a patch file, or a link to your fork.
   It is reviewed, applied in the private repository, and returns here on the next export
   **with your authorship preserved in the commit trailer**.
3. **Expect a delay.** This is a single-maintainer project and the mirror refreshes in
   batches, not on every commit. A change may be live on the platform before it appears
   here.

## Licensing of contributions

There is no Contributor Licence Agreement. By submitting a patch you licence it under
AGPL-3.0, the same terms as the rest of the repository. See `LICENSE` and
`LICENSE-ADDITIONAL-TERMS.md`.

## What a useful report contains

For a bug: what you did, what happened, what you expected, and the exact error text
rather than a paraphrase of it. For a rendering problem: the layer id and the zoom level,
because most layer bugs are specific to one of the two.

For a data question — a value that looks wrong, a source that looks stale — say which
layer and which feature. Data issues are frequently upstream rather than in this code,
and naming the feature is what makes that distinguishable.

## Data, licences, and what cannot be accepted

`DATA-LICENCES.md` records the terms of every upstream source. Two of them constrain
contributions directly:

- **Do not add a layer whose licence forbids redistribution through an interactive map
  with download access.** Two layers have already been withdrawn from the platform under
  exactly that clause. A layer that cannot be served is not a layer.
- **Do not add a data file to this repository.** The engine fetches from upstream at
  runtime; committing a copy would redistribute it under terms this repository cannot
  grant, whatever the code's own licence says.

## Security

Do not open an Issue for a suspected vulnerability. `SECURITY.md` has the private
reporting address.
